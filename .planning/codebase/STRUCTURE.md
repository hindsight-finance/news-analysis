## Directory Purposes

**Project root:**
- Purpose: All analysis scripts live here as flat Python modules
- Contains: `main.py`, `exploration.py`, `causal_analysis.py`, `forward_returns.py`, `injection.py`
- Key files: `main.py` (produces the sweep results artifact), `forward_returns.py` (independent return analysis)

**`data/`:**
- Purpose: Raw parquet inputs and generated intermediate results
- Contains: Source data files and `sweep_analysis_results.parquet` generated by `main.py`
- Key files: `nq_1m.parquet` (price history), `economic_events.parquet` (event calendar)
- Generated: `sweep_analysis_results.parquet` is generated; the two source parquets are external
- Committed: No (gitignored)

**`charts/`:**
- Purpose: All generated chart images and summary CSV files
- Contains: PNG charts and CSV outputs organized by analysis type
- Key files: `charts/forward_returns/forward_returns_by_event.csv`, `charts/causal/event_stats.csv`, `charts/exploration/summary_by_event.csv`
- Generated: Yes (produced by running analysis scripts)
- Committed: Yes (checked in to repo)

**`charts/causal/`:**
- Purpose: Outputs from `causal_analysis.py`
- Contains: `feature_importance.png`, `decision_tree.png`, `logistic_coefficients.png`, `event_edge.png`, `event_stats.csv`

**`charts/exploration/`:**
- Purpose: Outputs from `exploration.py`
- Contains: `momentum_vs_reversal_by_event.png`, `momentum_vs_reversal_by_release_time.png`, `win_rate_by_range_quartile.png`, `mae_distribution.png`, `summary_by_event.csv`

**`charts/forward_returns/`:**
- Purpose: Outputs from `forward_returns.py`
- Contains: Per-horizon PNGs (`forward_returns_<N>m_*.png`) and `forward_returns_by_event.csv`
- Naming pattern: `forward_returns_{horizon}m_{chart_type}.png` (e.g., `forward_returns_30m_raw_by_direction.png`)

**`tests/`:**
- Purpose: pytest unit tests covering public functions in the analysis scripts
- Contains: Three test modules, each focused on one or two analysis scripts
- Key files: `test_forward_returns.py` (most complete; covers `build_forward_returns`, `write_outputs`, direction helpers)

**`docs/superpowers/plans/`:**
- Purpose: Implementation plan documents written during feature development
- Contains: Markdown files prefixed with date (`YYYY-MM-DD-<feature>.md`)
- Key files: `2026-05-11-forward-returns.md`, `2026-05-11-forward-mae-mfe-profiles.md`

**`docs/superpowers/specs/`:**
- Purpose: Design specs for planned features
- Contains: Markdown files prefixed with date (`YYYY-MM-DD-<feature>-design.md`)
- Key files: `2026-05-11-forward-returns-design.md`, `2026-05-11-forward-mae-mfe-profiles-design.md`

## Naming Conventions

**Files:**
- Analysis scripts: lowercase with underscores (`main.py`, `causal_analysis.py`, `forward_returns.py`)
- Test files: `test_<subject>.py` mirroring the module or topic tested (`test_forward_returns.py`)
- Chart outputs: lowercase with underscores and horizon suffix for forward returns (`forward_returns_30m_raw_by_direction.png`)
- Plan/spec docs: `YYYY-MM-DD-<feature-slug>.md` (e.g., `2026-05-11-forward-returns.md`)

**Directories:**
- All lowercase with underscores (`forward_returns/`, `causal/`)

**Functions:**
- Public analysis functions use `snake_case` verbs: `load_data`, `analyze_event`, `build_forward_returns`, `compute_win_rates`, `build_features`
- Helper functions use `snake_case` descriptive names: `ensure_utc`, `find_sorted_pos`, `add_lookup_tables`, `qcut_with_fallback_labels`
- Plot functions prefixed with `plot_`: `plot_raw_by_direction`, `plot_event_win_rates`, `plot_feature_importance`

**Variables:**
- DataFrames: short lowercase (`df`, `nq`, `events`, `horizon_df`)
- Path constants: `UPPER_SNAKE_CASE` (`DATA_DIR`, `DEFAULT_OUTPUT_DIR`, `DEFAULT_HORIZONS`)

## Where to Add New Code

**New analysis script (independent pipeline):**
- Implementation: new `.py` file at project root following the `run()` + `parse_args()` + `if __name__ == "__main__"` pattern (see `forward_returns.py` as the canonical template)
- Output directory: new subdirectory under `charts/` (e.g., `charts/my_analysis/`)
- Tests: new `tests/test_<script_name>.py`

**New feature in an existing analysis script:**
- Add pure functions before the `run()` function; call them inside `run()`
- Mirror the function in `tests/` with a test covering the expected transformation

**Shared utility function (e.g., another use of `ensure_utc`):**
- Currently: copy-paste into the script (existing pattern)
- Preferred: create `utils.py` at project root and import from there (no such file yet — this would be a new addition)

**New output chart type in `forward_returns.py`:**
- Add a `plot_<name>(df, horizon, output_path)` function following the existing plot function signatures
- Call it inside `write_outputs()` (`forward_returns.py:295-306`)
- Add expected output filename to `test_write_outputs_creates_csv_and_expected_charts` in `tests/test_forward_returns.py`

**New horizon in `forward_returns.py`:**
- Update `DEFAULT_HORIZONS` tuple at `forward_returns.py:22`
- The test at `tests/test_forward_returns.py:111-114` asserts the exact tuple value and must be updated
