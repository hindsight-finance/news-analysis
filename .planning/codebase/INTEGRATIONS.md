## Data Storage

**Databases:**
- None — no database connections of any kind

**File Storage (local Parquet):**
- `data/economic_events.parquet` — US economic event calendar (2010-01-01 to 2026-03-31); columns include `datetime_utc`, `title`, `currency`, `impact`; read by `main.py`, `injection.py`, and `forward_returns.py`
- `data/nq_1m.parquet` — NQ 1-minute OHLCV bars (2010-06-06 to 2026-03-15); columns include `DateTime_UTC` (or `datetime_utc`), `Open`, `High`, `Low`, `Close`, `Volume`; read by `main.py`, `injection.py`, and `forward_returns.py`
- `data/sweep_analysis_results.parquet` — generated by `main.py`; consumed by `exploration.py` and `causal_analysis.py`; columns include sweep timing, MAE, range metrics, and session context features
- All three paths are gitignored via `data/` entry in `.gitignore`

**Parquet I/O client:** `pandas.read_parquet` / `DataFrame.to_parquet` (pyarrow backend)

**Output file storage (local):**
- `charts/` directory — PNG chart outputs from all analysis scripts
- `charts/exploration/summary_by_event.csv` — written by `exploration.py`
- `charts/causal/event_stats.csv` — written by `causal_analysis.py`
- `charts/forward_returns/forward_returns_by_event.csv` — written by `forward_returns.py`
